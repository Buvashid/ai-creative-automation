# AI Tools Used

## 1. Copilot 

Copilot was used as a development assistant for:
- Planning the project structure and workflow.
- Discussing implementation approaches and troubleshooting.
- Drafting and improving project documentation.

## 2. AI Tools Used for Creative Generation

No external AI text-generation API or AI image-generation model was integrated into the creative-generation pipeline.

The 20 final creatives were generated using deterministic Python code, predefined copy-generation rules, and a reusable image template.

## 3. Transparency and Limitations

Copilot assisted with project development, but this does not mean the final headlines or images were AI-generated.

The current implementation does not fully satisfy the assignment's requirement for AI-generated headlines and images. This limitation is documented transparently.

## 4. Reproducing the Results

The current creatives can be regenerated using the Python pipeline and the dataset in `data/creatives.csv`.

Refer to the main `README.md` for setup instructions and commands.

No AI API key is required to run the existing pipeline.
