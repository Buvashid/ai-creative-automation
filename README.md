# PaisaPath — One Template, Twenty Creatives

PaisaPath is a Python-based creative automation project developed for the Yanisa Execution assignment. It transforms 20 structured creative specifications into branded, 1080 × 1080 personal-finance demonstration advertisements using a reusable template and a reproducible generation pipeline.

The project demonstrates how structured data, automated copy preparation, multilingual text rendering, validation, and quality reporting can reduce repetitive creative-production work while preserving supplied offers.

**Disclaimer:** PaisaPath and all offers in this repository are fictional. The creatives are demonstration material, not real financial products or financial advice.

---

## 1. Brand Identity

- **Brand:** PaisaPath
- **Category:** Personal finance education and budgeting
- **Brand personality:** Clear, approachable, practical, and responsible
- **Tone of voice:** Simple, encouraging, and informative
- **Primary color:** Deep navy `#102A43`
- **Secondary color:** Warm cream `#F7F1E5`
- **Accent color:** Gold `#D9A441`
- **Canvas:** 1080 × 1080 pixels
- **Brand name treatment:** PaisaPath wordmark rendered as text in the template

The visual system uses a consistent square-advertisement layout, shared typography, and a restrained color palette. The reusable template maintains the brand identity while allowing individual creatives to change according to their CSV specifications.

The final images are rendered using deterministic Python code rather than an external image-generation model.

## 2. Features

- Reusable 1080 × 1080 creative template.
- CSV-driven generation for 20 creative specifications.
- English, Hindi, and Marathi copy support.
- Required-field, duplicate-ID, language, blank-value, and row-count validation.
- Copy preparation that preserves supplied offers.
- Language-specific disclaimers.
- Per-creative failure handling.
- Automated tests for loading, validation, copy generation, rendering, and pipeline execution.
- Generation reports and a separate manual QA log.
- Documented setup and reproduction steps.

## 3. Pipeline Architecture

```text
data/creatives.csv
        |
        v
CSV loading and normalization
        |
        v
Dataset validation
        |
        v
Structured copy preparation
        |
        v
Multilingual text shaping and rendering
        |
        v
1080 × 1080 PNG outputs
        |
        v
Quality report and manual QA log
```

The pipeline validates the dataset before generation. Invalid required fields, duplicate IDs, unsupported languages, or an incorrect row count can block the batch. Individual rendering failures are recorded so later rows can still be processed.

## 4. Template Design

The master template separates shared design elements from creative-specific content.

| Element | Treatment |
|---|---|
| Canvas dimensions | Locked at 1080 × 1080 |
| Brand name and visual identity | Shared across creatives |
| Color palette | Shared across creatives |
| Product | Data-driven |
| Audience | Data-driven |
| Offer | Data-driven; supplied text is preserved |
| Language | Data-driven |
| Disclaimer | Selected according to language |
| Typography and text positioning | Controlled by the renderer |
| Final PNG | Generated by the pipeline |

The reusable template is intended to maintain visual consistency across the complete creative set.

## 5. Technology Stack

- **Python:** Pipeline and application logic
- **Pandas:** CSV loading and data handling
- **Pillow:** Image composition and PNG output
- **HarfBuzz:** Complex-script text shaping
- **FreeType:** Font loading and glyph rendering
- **pytest:** Automated testing

The implementation uses deterministic templates and predefined copy-generation rules. The final PNG files are not generated by an external AI image-generation model.

## 7. Windows Setup

Open PowerShell in the project root.

### Create and activate a virtual environment

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
```

### Install dependencies

```powershell
python -m pip install -r requirements.txt
```

### Configure the Devanagari font

Hindi and Marathi rendering requires a compatible Devanagari font. On Windows, Nirmala UI is one possible option.

For the development environment used for this project:

```powershell
$env:PAISAPATH_DEVANAGARI_FONT_PATH = "C:\Windows\Fonts\Nirmala.ttc"
```

This environment variable applies to the current PowerShell session. If the font is installed elsewhere, configure the actual path available on your system.

## 8. Run the Pipeline

With the virtual environment activated and the font configured, run:

```powershell
python -m app.main
```

To generate the three-language sample set, run:

```powershell
python -m app.generate_samples
```

The main pipeline reads the creative specifications, validates the dataset, prepares the copy, renders the outputs, and writes the quality report.

**Note:** Running the pipeline can regenerate output files and reports. Preserve any manual QA records you need before regenerating them.

## 9. Run Automated Tests

Execute:

```powershell
python -m pytest
```

**Latest locally verified result: 51 tests passed in 4.82 seconds.**

This result describes the test run recorded during development. Re-run the command against the checked-out revision to verify the current environment.

Automated tests verify program behavior; they do not establish that every creative is aesthetically effective, linguistically natural, or suitable for publication.
